## Translation policy

- English is canonical for commands, identifiers, security details, and
  current compatibility claims.
- Preserve `Direct`, `Astrill`, `tun0`, file paths, and CLI commands exactly.
- Provider country describes catalog metadata; endpoint country describes the
  one shared Astrill tunnel.
- Do not translate a feature as enforcing until its English documentation says
  it is enforcing.
- Keep all 11 language links at the top of every localized README.
