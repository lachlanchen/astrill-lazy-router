# Astrill Lazy Policies

This repository is the public, credential-free deployment mirror for the
[Astrill Lazy policy workspace](https://lachlanchen.github.io/astrill-lazy-policies/).
It contains catalog metadata and service-level Direct or Astrill decisions
only.

The stable policy is published at
[`policies/daily-balanced-v1.json`](policies/daily-balanced-v1.json).
[`data/release.json`](data/release.json) records its exact SHA-256 digest.
The desktop import command requires that digest and changes local policy only;
router deployment remains a separate confirmed action.

No router address, device address, MAC address, SSH key, Astrill credential,
installer URL, or installer token is permitted in this repository. The router
does not execute content from this website.
